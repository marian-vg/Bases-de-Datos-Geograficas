# North symbol provenance

`norte.svg` is an **unmodified, byte-identical copy** of
`/usr/share/qgis/svg/arrows/NorthArrow_07.svg` supplied by QGIS 3.34.4.
It is the standard cardinal compass rose (N/E/S/W), not a custom drawing.
Black fill and outline are native QGIS picture settings; the source is unchanged.

Upstream: QGIS, `images/svg/arrows/NorthArrow_07.svg` in the QGIS source tree.
Installed Debian package copyright: `/usr/share/doc/qgis-common/copyright`;
its default file license is GPL-2+ (GNU GPL version 2 or later). The GPL v2 text
is included as `LICENCIA-QGIS-SVG.txt`. Copyright remains with the QGIS
contributors listed in the package copyright metadata.

The former `NorthArrow_04.svg` chevron was replaced because its appearance was
not suitable for the requested report styling, despite also being a stock asset.
